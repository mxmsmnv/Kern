# Changelog

All notable public changes to Kern are documented here.

## [1.0.0] - 2026-08-24

### Added

- First public release.
- Page ownership claims through moderated requests or one-time access codes.
- Composable access rules for templates, fields, roles, users and active claimants.
- Moderated Page revisions with optimistic conflict detection and explicit overrides.
- Immutable audit history for claims, codes, revisions and access-rule changes.
- Field adapters for native ProcessWire fields, Rapid, Combo, Table, Repeater and RepeaterMatrix values.
- Responsive ProcessWire admin workspaces for moderation, delegated access and policy management.
